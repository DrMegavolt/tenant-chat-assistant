01 — TRACES

Follow one request

Across retrieval, prompt assembly, the model call and every tool — one span each, stitched by a single trace id.

02 — EVALS

Score quality continuously

Golden sets, graders and regression gates run on every change — so quality drift shows up in CI, not in Slack.

03 — COST

Tokens are money

Attribute spend per tenant, per feature, per release. A prompt tweak is a pricing decision.

Instrumentation05 / 06

One request, one trace

  • Prompt hash + template version — not raw text alone
  • Retrieved chunks with ids and scores, so hallucination is traceable
  • Model and params — temperature, max tokens, provider
  • Tool calls with inputs, outputs and retries
  • Tokens and latency per hop — the raw material of every cost view
